# Конституция РФ — интерактивный учебник

Учебный сайт для изучения Конституции Российской Федерации: полный текст, объяснения, практика Конституционного Суда, интерактивные схемы, кейсы, задания и ситуационный тренер.

## Интерфейс

- Главная страница с интерактивной обложкой и оглавлением всех глав.
- Отдельная область чтения, выбор темы и семь режимов изучения.
- Поиск по номерам статей, темам и тексту Конституции (Ctrl/Cmd + K).
- Оглавление и настройки доступны на компьютере и телефоне.
- Ссылки на конкретную главу, тему и режим, поддержка кнопки «Назад» браузера.
- Прогресс сохраняется в прежнем ключе `gmu_const_v7`, место чтения — в `constitution_location`.
- Обратная связь по заданиям остаётся видимой до нажатия «Следующее задание».
- Локальный шрифт Golos Text, клавиатурная навигация и поддержка уменьшенного движения.

## Файлы

`app.js` содержит исходный учебный корпус и учебную механику. Новый интерфейс находится в `site-v10.js` и `site-v10.css`. Предыдущие версии сохранены в репозитории. Шрифт распространяется по SIL Open Font License, текст лицензии находится в `assets/OFL-Golos-Text.txt`.

Ситуационный тренер использует локальную проверку ключевых элементов ответа; внешняя ИИ-модель не подключена.

## Публикация

Статический сайт без сборки. GitHub Pages публикует `index.html` из корня ветки `main`.
