# ГМУ · Конституция РФ — интерактивный тренажёр

Полноэкранный учебный сайт по Конституции Российской Федерации для курса ГМУ.

## Что внутри

- горизонтальная навигация без длинного вертикального скролла;
- полный атлас Конституции;
- тренировочный режим с неограниченными попытками;
- XP, уровни, серии, множитель, достижения и ежедневная миссия;
- практические управленческие кейсы;
- экзамен на 20, 50 или полный набор контрольных точек;
- прогресс хранится локально в браузере.

## GitHub Pages

Главный файл сайта — `index.html`. После включения GitHub Pages сайт можно публиковать непосредственно из корня ветки `main`.
